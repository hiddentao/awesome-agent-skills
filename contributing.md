# Contribution guide

This list holds only skills and commands that [hiddentao](https://github.com/hiddentao) wrote or translated. It does not accept skills that other people send in.

If a link is broken or a description is wrong, open an issue or a pull request that fixes it. Keep each entry in this format: `- [name](link) - Description.` The description starts with a capital letter and ends with a period.

New skills are added here when they are published.
